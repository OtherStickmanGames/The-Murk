# M0 — Основа

Цель этапа: карту можно крутить на телефоне при 30 fps.
Разделы GDD: «Мир», «Интерфейс», «Визуальный стиль», «Технологии».

Проверяем в редакторе Unity через Device Simulator (переключатель Game / Simulator в окне Game). Телефон нужен к M0.4 (жесты) и M0.5 (производительность): к этому моменту включи на нём режим разработчика и отладку по USB.

У каждой задачи указаны модель и эффорт — выставь их в меню модели при открытии сессии.

- [x] **M0.1 Каркас проекта.** Папки и asmdef по `CLAUDE.md`; явно прописать в `Packages/manifest.json` пакеты Burst, Collections, Mathematics и Newtonsoft.Json — сейчас они есть только как зависимости других пакетов; сцена `Bootstrap` с точкой входа; настройки Android — IL2CPP, ARM64, только портрет, `Mobile_RPAsset`; заготовка отладочной консоли со счётчиком FPS. Удалить `TutorialInfo` и `SampleScene`.
  *Готово, когда:* пустая сцена со счётчиком FPS запускается в Device Simulator в портретной ориентации, а APK под Android собирается без ошибок.
  *Модель:* Opus 5.5, эффорт max — закладывается архитектура всего проекта.

- [ ] **M0.2 Воксельные данные и генерация.** Хранилище блоков 160×160×64 чанками 32³ в `Game.Sim`; типы блоков из JSON; генерация по сиду в `Game.Gen` через FastNoiseLite: поверхность на высоте 32–56 блоков, нижние 4 слоя — неразрушимое дно; равнины, холмы, реки и рудные жилы по глубине (GDD, «Генерация региона» и «Добыча»).
  *Готово, когда:* EditMode-тесты проходят — один сид даёт одинаковую карту, руда лежит на своих глубинах; время генерации выводится в лог.
  *Модель:* Opus 5.5, эффорт max — на хранилище блоков опираются все будущие системы.

- [ ] **M0.3 Меши чанков.** Жадный мешинг на Burst; цвет вершин из палитры биома с лёгким шумом оттенка; затенение углов блоков; перестраивается только изменённый чанк.
  *Готово, когда:* карта видна целиком; команда консоли «удалить блок» сразу обновляет меш.
  *Модель:* Opus 5.5, эффорт xhigh.

- [ ] **M0.4 Камера и жесты.** Наклон 50–60°; сдвиг одним пальцем, зум щипком, поворот двумя пальцами с шагом 45°; камера не выходит за границы карты. В редакторе — управление мышью.
  *Готово, когда:* на телефоне всё управляется одной рукой, камеру нельзя увести за карту.
  *Модель:* Opus 5.5, эффорт high.

- [ ] **M0.5 Производительность.** Замер FPS, вызовов отрисовки и памяти на телефоне; оптимизация до бюджетов из `CLAUDE.md`.
  *Готово, когда:* вся карта держит 30 fps, цифры записаны в таблицу ниже.
  *Модель:* Opus 5.5, эффорт xhigh — оптимизация требует замеров и анализа.
